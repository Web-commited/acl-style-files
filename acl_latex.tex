\begin{abstract}
% ================================================================

Automated fact-checking requires retrieving relevant evidence from a
large corpus and classifying claims based on that evidence.
A recurring difficulty in this task is the \textsc{Disputed} class,
which requires detecting that credible evidence exists on \emph{both
sides} of a claim --- a signal that standard concatenation-based
classifiers struggle to capture.
We build a system for verifying climate science claims against a corpus
of 1.2 million passages and explore three directions:
(1)~a \textbf{conflict-aware aggregation} method that scores each
evidence passage independently using Natural Language Inference (NLI),
extracts features about inter-evidence conflict, and feeds them to a
lightweight classifier --- this produces non-trivial \textsc{Disputed}
predictions (16.7\%, up from 0\% in concatenation-based systems);
(2)~\textbf{NLI transfer learning} for classification, which improves
minority-class accuracy by 7--15 percentage points by giving the
classifier pretrained knowledge of entailment and contradiction;
(3)~a \textbf{hard-negative cross-encoder reranker} that distinguishes
logically relevant evidence from topically similar passages, improving
evidence F@5 from 0.144 to 0.211.
Our best system achieves a Harmonic Mean of 0.334 on the development
set.
The conflict-aware approach shows that \textsc{Disputed} detection
benefits from dedicated architectural support beyond standard sequence
classification.

\end{abstract}

\section{Introduction}
% ================================================================

The spread of unverified claims about climate science has made automated
fact-checking an increasingly important NLP task
\citep{diggelmann-etal-2020-climate}.
Given a claim in natural language, a fact-checking system must
(1)~retrieve the most relevant evidence passages from a large corpus,
and (2)~classify the claim as \textsc{Supports}, \textsc{Refutes},
\textsc{Not\_Enough\_Info}, or \textsc{Disputed} based on that evidence.

The common approach is to concatenate retrieved evidence into one input
sequence and fine-tune a pretrained language model for classification.
This works when all evidence points in the same direction, but it has
a key limitation: when evidence passages \emph{conflict} --- some
supporting the claim, others refuting it --- the model has to resolve
these contradictions implicitly in a single forward pass.
The \textsc{Disputed} label is exactly the case where this fails,
because it requires detecting that credible evidence exists on both
sides, not just finding one consistent relationship.

We address this with four design choices:
\begin{itemize}
  \item We show that a \textbf{cross-encoder reranker} trained on
        hard negatives from the coarse retrieval pool improves the
        precision problem in hybrid bi-encoder retrieval (F@5: 0.144
        $\to$ 0.211), confirming that the bottleneck is ranking,
        not recall.
  \item We show that \textbf{NLI transfer learning} provides useful
        inductive bias for fact-verification, improving
        \textsc{Refutes} by 7.4 and \textsc{Not\_Enough\_Info} by 14.6
        percentage points through pretrained entailment representations.
  \item We propose \textbf{conflict-aware feature aggregation} using
        per-evidence NLI scoring, producing non-trivial
        \textsc{Disputed} predictions (16.7\%) where all
        concatenation-based systems get 0\%.
  \item We develop an \textbf{end-to-end evidence-aware verifier} with
        learned attention gating and per-evidence role prediction,
        achieving our best Harmonic Mean (0.334) and the best
        \textsc{Not\_Enough\_Info} accuracy (58.5\%).
\end{itemize}

We develop these techniques across five system variants,
measuring retrieval and classification separately at each stage to
see the effect of each design choice clearly.

\section{Approach}
% ================================================================

Our system follows a retrieve-then-classify pipeline.
We first describe the retrieval backbone (Sections~\ref{sec:retrieval-base}
and~\ref{sec:reranker}), then the classification methods that are
our main contributions (Sections~\ref{sec:nli-transfer}
and~\ref{sec:conflict}).

% ----------------------------------------------------------------
\subsection{Retrieval Backbone}
\label{sec:retrieval-base}
% ----------------------------------------------------------------

\paragraph{Hybrid bi-encoder retrieval.}
We build a hybrid retriever that combines sparse and dense signals.
The sparse part indexes all 1.2 million evidence passages with TF-IDF
(sklearn, max\_features = 100{,}000, English stop words removed)
\citep{manning-etal-2008-ir}.
The dense part encodes passages using \texttt{bge-base-en-v1.5}
\citep{xiao-etal-2023-bge}, a 110M-parameter encoder that produces
768-dimensional L2-normalised embeddings designed for retrieval.
We merge the two ranked lists with Reciprocal Rank Fusion (RRF)
\citep{cormack-etal-2009-reciprocal}:
\begin{equation}
  \text{RRF}(d) = \sum_{r \in \{\text{TF-IDF},\, \text{BGE}\}}
  \frac{1}{k + \text{rank}_r(d)}, \quad k = 60
\end{equation}

The hybrid gets F@5 = 0.144 on the development set --- slightly below
TF-IDF alone (0.147), because the dense retriever brings in
lower-precision candidates.
However, the hybrid's Recall@100 = 60.7\% is much higher than either
part alone, meaning the correct evidence is already in the top-100
pool for most claims.
So the hybrid's value is in building a high-recall pool for reranking,
not in top-5 precision directly.

% ----------------------------------------------------------------
\subsection{Hard-Negative Cross-Encoder Reranking}
\label{sec:reranker}
% ----------------------------------------------------------------

\paragraph{Motivation.}
Bi-encoders score query and document separately, so they capture
topical similarity but not the logical relationship between a claim
and a passage \citep{nogueira-cho-2019-passage}.
For example, a passage saying ``CO$_2$ levels have risen 40\%'' is
topically close to a claim about climate sensitivity, but it is not
actually useful as evidence for or against that claim.
Since Recall@100 is already 60.7\%, the problem is not finding
evidence but instead ranking.

\paragraph{Method.}
We fine-tune \texttt{DeBERTa-v3-base} \citep{he-etal-2021-deberta} as
a binary cross-encoder reranker.
The important design choice is how we build training negatives:
\begin{itemize}
  \item \textbf{Positives}: (claim, ground-truth evidence), label = 1.
  \item \textbf{Hard negatives}: (claim, non-GT passage from the top-100
        pool), label = 0, sampled at 3:1 ratio.
\end{itemize}
We use passages from the coarse pool as negatives instead of random
corpus passages.
These are hard negatives because they are topically related to the
claim (they passed the bi-encoder filter) but are not actual evidence.
This pushes the reranker to learn logical relevance, not just topical
filtering --- the bi-encoders already handle that part.
Training details: 3 epochs, batch size = 16 with gradient accumulation
over 2 steps (effective batch 32), lr = 2e-5, max\_length = 256, fp16.
At inference, we score all 100 candidates and pick the top-5.

\paragraph{Result.}
The reranker raises F@5 from 0.144 to 0.211 while
Recall@100 stays around the same, indicating that the gain comes from
better ranking within the existing pool rather than finding new
candidates.

% ----------------------------------------------------------------
\subsection{NLI Transfer for Classification}
\label{sec:nli-transfer}
% ----------------------------------------------------------------

\paragraph{Motivation.}
With better retrieval in place, classification becomes the next focus.
Looking at per-class numbers, a DeBERTa-v3-base classifier trained
from generic pretraining gets 77.9\% on \textsc{Supports} but only
51.9\% on \textsc{Refutes} and 36.6\% on \textsc{Not\_Enough\_Info}.
Our hypothesis is that this is because the model starts with no understanding of
entailment or contradiction --- it has to learn these concepts from
scratch on our small training set.

Natural Language Inference (NLI) pretraining gives exactly this kind
of knowledge.
NLI models learn to classify premise--hypothesis pairs as
entailment, contradiction, or neutral, which
maps well onto our fact-verification labels.

\paragraph{Method.}
We swap the generic DeBERTa initialisation for
\texttt{cross-encoder/nli-deberta-v3-base}
\citep{reimers-gurevych-2019-sentence}, which was fine-tuned on SNLI
\citep{bowman-etal-2015-snli} and MultiNLI
\citep{williams-etal-2018-multinli}.
We extend the classification head from 3 to 4 labels (adding
\textsc{Disputed} with random initialisation).
Training uses a two-stage procedure:
\begin{enumerate}
  \item \textbf{Stage 1} (10 epochs, lr = 2e-5): train on ground-truth
        evidence, so the model gets clean signal about claim--evidence
        relationships.
  \item \textbf{Stage 2} (5 epochs, lr = 5e-6): fine-tune on retrieved
        evidence, so the model adapts to the noisy evidence it will
        actually see at test time.
\end{enumerate}

\paragraph{Result.}
NLI initialisation raises accuracy from 54.6\% to 59.1\%, with the
gains concentrated on minority classes: \textsc{Refutes} +7.4pp
(51.9\% $\to$ 59.3\%) and \textsc{Not\_Enough\_Info} +14.6pp (36.6\%
$\to$ 51.2\%).
This suggests that NLI pretraining gives the model a more informed starting
point for distinguishing contradiction from neutral evidence.
However, \textsc{Disputed} drops from 11.1\% to 5.6\%: Our hypothesis is that the NLI
model's stronger sense of ``neutral'' causes it to absorb some
borderline disputed cases into \textsc{Not\_Enough\_Info}.
This motivates building explicit conflict detection in the next system.

% ----------------------------------------------------------------
\subsection{Per-Evidence NLI with Conflict-Aware Aggregation}
\label{sec:conflict}
% ----------------------------------------------------------------

\paragraph{Motivation.}
All previous classifiers concatenate retrieved evidence into one input
sequence.
This creates a problem: when passages conflict, the model has to figure
out the contradictions on its own within a single forward pass.
The \textsc{Disputed} label which needs detection of credible
evidence on both sides is where this potentially breaks down.
Across many of our concatenation-based variants, \textsc{Disputed} accuracy
stays at or near 0\%.

Recent work has shown that reasoning over evidence \emph{sets} rather
than concatenated strings helps verification quality
\citep{shang-etal-2024-rafts, kapadia-etal-2025-minimal}.
Our main idea is as follows: inter-evidence conflict, which is when some
passages entail the claim while others contradict, it should as a result, be a
direct input to the classifier, not something the model has to discover
on its own from the token sequence.

\paragraph{Per-evidence NLI scoring.}
Instead of concatenating all top-5 passages together, we score each
passage separately against the claim using the NLI model.
For each (claim, evidence$_i$) pair, we get a 3-dimensional probability
vector:
\begin{equation}
  \mathbf{p}_i = [\,P(\text{contradiction}),\; P(\text{entailment}),\;
  P(\text{neutral})\,]
\end{equation}
This gives us a per-claim evidence signal matrix
$\mathbf{P} \in \mathbb{R}^{k \times 3}$, where each row tells us
how one piece of evidence relates to the claim.

\paragraph{Conflict-aware feature extraction.}
From $\mathbf{P}$, we compute 19 features that capture four kinds of
information:
\begin{itemize}
  \item \textbf{Aggregate statistics} (9): mean, max, and standard
        deviation of each NLI dimension across passages.
  \item \textbf{Dominance} (3): what fraction of passages have each NLI
        label as their highest probability.
  \item \textbf{Conflict indicators} (4): the minimum of max-entailment
        and max-contradiction (this is high when both exist),
        entropy of dominant labels, and fraction of mixed-signal
        passages.
  \item \textbf{Sufficiency} (3): fraction of informative (non-neutral)
        passages, average confidence, and evidence count.
\end{itemize}

The conflict indicators are the key features for \textsc{Disputed}:
they fire when some passages entail the claim while others contradict
it, which is the definition of this class.

\paragraph{Hybrid aggregation.}
We combine the 19 conflict features with 12 features from the NLI
classifier's output (4-class logits, softmax probabilities, and
log-probabilities).
The full 31-dimensional vector goes into a lightweight MLP (64--32
hidden units, ReLU, L2 regularisation $\alpha = 0.01$).
This way the aggregator can use both the classifier's overall judgment
and the per-evidence conflict patterns together.

\paragraph{Result.}
We evaluated three aggregator variants: logistic regression (unbalanced
and balanced) and an MLP (64--32 hidden units, ReLU, L2 $\alpha = 0.01$).
The MLP achieves the best harmonic mean and gets
\textsc{Disputed} = 16.7\% (3/18 correct) which is our first system to
predict this class in a meaningful way.
With balanced class weights (logistic regression variant),
\textsc{Disputed} reaches 33.3\% (6/18) but overall accuracy drops
from 55.8\% to 51.3\%.
Ablation shows that removing the conflict features while keeping the
DeBERTa logits brings \textsc{Disputed} back to near 0\%, confirming
that these features carry signal that concatenation-based approaches
do not.

\subsection{System 5 --- End-to-End Evidence-Aware Verifier}
\label{sec:system5}
% ----------------------------------------------------------------

\paragraph{Motivation.}
System 4 demonstrated that per-evidence reasoning improves
\textsc{Disputed} detection, but its two-branch design has a
fundamental limitation: the DeBERTa classifier and the NLI scorer
are trained independently, and only a lightweight sklearn MLP
connects them.
Gradients cannot flow from the final prediction back through the
evidence encoder, so the encoder never learns to produce
representations optimised for conflict detection.
This system therefore trains a model to learn per-evidence reasoning end-to-end
without relying on a frozen NLI model or hand-crafted features.

\paragraph{Architecture.}
We replace the two-branch post-hoc aggregation with a single
end-to-end model (Figure~\ref{fig:system5}).
Given a claim and $k{=}5$ retrieved evidence passages, the model
proceeds in five stages:

\begin{enumerate}
  \item \textbf{Per-evidence encoding.}
        Each (claim, evidence$_i$) pair is encoded independently
        through a shared \texttt{nli-deberta-v3-base} encoder with
        gradient checkpointing enabled, producing $k$ CLS
        representations $\mathbf{h}_1, \ldots, \mathbf{h}_k \in
        \mathbb{R}^{768}$.

  \item \textbf{Learned attention gating.}
        A two-layer gate network scores each representation:
        \begin{equation}
          \alpha_i = \frac{\exp(g(\mathbf{h}_i))}
                         {\sum_{j=1}^{k} \exp(g(\mathbf{h}_j))},
          \quad g = W_2 \tanh(W_1 \mathbf{h}_i)
        \end{equation}
        where invalid positions are masked to $-\infty$ before softmax.
        The pooled representation is
        $\bar{\mathbf{h}} = \sum_i \alpha_i \mathbf{h}_i$.
        This lets the model downweight irrelevant or empty evidence
        slots.

  \item \textbf{Per-evidence role prediction.}
        A linear head predicts a 3-class role distribution
        (support/refute/neutral) for each passage:
        $\mathbf{r}_i = \text{softmax}(W_r \mathbf{h}_i)$.
        This is similar to System 4's NLI scoring, but trained
         with the final classification objective rather than
        frozen.

  \item \textbf{Structured conflict features.}
        From the gated role predictions, we compute 7 features:
        \begin{itemize}
          \item Top weighted support, refute, and neutral scores
          \item Summed support and refute mass across all passages
          \item \textbf{Conflict strength}:
                $\min(\max_i(\alpha_i \cdot r_i^{\text{sup}}),\;
                       \max_i(\alpha_i \cdot r_i^{\text{ref}}))$
          \item Active evidence count minus support--refute gap
        \end{itemize}
        The conflict strength feature is high exactly when the model
        attends to both supporting and refuting passages, which is the
        signal needed for \textsc{Disputed}.

  \item \textbf{Classification.}
        The pooled representation $\bar{\mathbf{h}}$ is concatenated
        with the 7 structured features and passed through a two-layer
        MLP (768$\to$768, LayerNorm, GELU, dropout 0.1, 768$\to$4)
        to produce the final 4-class prediction.
\end{enumerate}

\paragraph{Training procedure.}
We use the same two-stage schedule as System 3:
\begin{itemize}
  \item \textbf{Stage 1} (6 epochs, lr = 2e-5): train on ground-truth
        evidence so the encoder and role head learn clean
        claim--evidence relationships.
  \item \textbf{Stage 2} (3 epochs, lr = 5e-6): fine-tune on retrieved
        evidence from the V4 reranker, adapting to the noise the model
        will see at inference.
\end{itemize}
Both stages use AdamW with linear warmup (10\%) and linear decay,
batch size 2 with gradient accumulation over 4 steps (effective
batch 8), max sequence length 192, and gradient clipping at 1.0.
The reduced sequence length (192 vs.\ 512 in System 3) is necessary
because encoding $k{=}5$ pairs per claim multiplies memory usage
by 5$\times$; gradient checkpointing recovers some of this but the
T4's 15GB VRAM remains the binding constraint.

\paragraph{Result.}
System 5 achieves 59.1\% accuracy and a Harmonic Mean of 0.334, which is
the best among our systems.
The most notable per-class change is on \textsc{Not\_Enough\_Info}
(58.5\%, up from 36.6\% in System 2 and 51.2\% in System 3),
suggesting that per-evidence encoding helps the model recognise when
\emph{none} of the retrieved passages individually entails the claim.
\textsc{Refutes} returns to 55.6\% (matching System 2), and
\textsc{Supports} remains at 76.5\%.

However, \textsc{Disputed} remains at 0\%.
The cross-entropy loss with uniform class weights does not encourage
learning this minority class (only 18 dev examples).
We experimented with class-weighted loss, which raised
\textsc{Disputed} to 28\% but dropped the Harmonic Mean to 0.23
because the model over-predicted \textsc{Disputed} at the expense of
majority classes.

\section{Analysis}
% ================================================================

\subsection{Why Concatenation Fails for DISPUTED}

\textsc{Disputed} is different from the other three labels in a basic
way.
\textsc{Supports}, \textsc{Refutes}, and \textsc{Not\_Enough\_Info}
each need the model to find one consistent relationship between the
claim and its evidence.
\textsc{Disputed} needs the model to notice that the evidence
\emph{itself} is inconsistent --- some passages support the claim
while others go against it.

When evidence are concatenated into one sequence, the logical
relationships get collapsed into one mixed representation.
The model sees tokens from supporting and refuting passages together,
but nothing tells it which passages agree and which disagree.
Per-evidence scoring keeps this structure intact: the conflict
indicators go high exactly when the evidence matrix has both
high-entailment and high-contradiction rows.

\subsection{NLI Transfer: Matching Pretraining to Task Structure}

The NLI $\to$ fact-verification transfer works partially because the label
systems line up well:
\emph{entailment} $\approx$ \textsc{Supports},
\emph{contradiction} $\approx$ \textsc{Refutes},
\emph{neutral} $\approx$ \textsc{Not\_Enough\_Info}.
The +14.6pp gain on \textsc{Not\_Enough\_Info} is notable: this class
needs the model to recognise that evidence is topically related but
does not actually say enough to verify the claim, which is a relationship
similar to the ``neutral'' category that NLI training covers.

The drop in \textsc{Disputed} (11.1\% $\to$ 5.6\%) under NLI transfer
shows an interesting failure: the model's stronger sense of ``neutral''
makes it label conflicting evidence as ``not enough info'' instead of
``disputed.''
Which entails that \textsc{Disputed} needs more explicit conflict detection.

\subsection{Reranking: From Topical to Logical Relevance}

The improvement in F@5 from the cross-encoder (0.144 $\to$ 0.211)
illustrates the difference between topical and logical relevance:
bi-encoders capture \emph{what} a passage is about, while
cross-encoders capture \emph{how} it relates to the claim.
By using passages from the coarse pool as negatives, we force it to
learn the harder distinction: logically relevant vs.\ merely topical.

\subsection{Qualitative Examples}

\paragraph{Conflict detection success.}
\emph{Claim:} ``Volcanoes emit around 0.3 billion tonnes of CO2 per
year.'' (GT: \textsc{Disputed})

The retrieved evidence includes ``400,000 $\pm$ 100,000 tonnes per
year'' (for a single volcano) and ``130 to 230 teragrams of carbon
dioxide per year'' (a global estimate).
The NLI model gives high entailment to the global estimate and moderate
contradiction to the single-volcano figure.
The conflict indicators pick up this mixed signal, and the aggregator
correctly predicts \textsc{Disputed}.
All concatenation-based systems predict \textsc{Supports} instead.

\paragraph{Retrieval failure fixed by reranking.}
\emph{Claim:} ``While members of the media may nod along to such claims
[about weather extremes], the evidence paints a different story.''
(GT: \textsc{Supports})

The bi-encoder retrieves topically similar but wrong passages (e.g.\
``There is no evidence to substantiate these unorthodox claims'').
The cross-encoder reranker finds the correct evidence about media
coverage of climate extremes, and the classifier then gets it right.

\paragraph{Classification failure even with correct retrieval.}
\emph{Claim:} ``[Riebesell] is a world authority on the topic and has
typically communicated cautiously about the effects of acidification.''
(GT: \textsc{Not\_Enough\_Info})

The reranker retrieves relevant passages about ocean chemistry, but the
classifier predicts \textsc{Supports}.
The evidence talks about the scientific field but says nothing about
Riebesell's communication style, which is a subtle difference between what
the claim is about and what it is actually asking.

\section{Conclusion}
% ================================================================

We built a fact-checking system for climate science claims, exploring
how per-evidence reasoning compares to standard concatenation-based
classification.
Our main observation is that per-evidence reasoning --- whether through
post-hoc conflict features (System 4) or end-to-end learned gating
(System 5) --- improves classification over concatenation (best
Harmonic Mean 0.334).
System 5's end-to-end evidence-aware verifier achieves the best
Harmonic Mean by combining reranked retrieval with learned
per-evidence attention, and reaches 58.5\% on \textsc{Not\_Enough\_Info}
(+22pp over the reranker baseline) by recognising when no individual
passage entails the claim.
System 4's conflict-aware aggregation is the only approach that
predicts \textsc{Disputed} at all (16.7\%), suggesting that explicit
conflict features carry signal that end-to-end training does not
surface without class balancing.
NLI transfer learning provides useful inductive bias for minority
classes (+14.6pp on \textsc{Not\_Enough\_Info}, +7.4pp on
\textsc{Refutes}).
Cross-encoder reranking improves retrieval F@5 from 0.144 to 0.211
by learning to distinguish logical relevance from topical similarity.

\textsc{Disputed} remains largely unsolved: with only 18 development
examples and a Recall@100 ceiling of 61\%, both data scarcity and
retrieval coverage limit what we can achieve.
Future work could add class-weighted loss to System 5's end-to-end
training, and explore multi-hop retrieval to actively find evidence on
both sides of a claim.

% ================================================================
\section*{Limitations}
% ================================================================

Our system has several constraints.
First, the T4 GPU (15GB VRAM) limits batch sizes --- particularly for
System 5, which encodes 5 (claim, evidence) pairs per example ---
and non-determinism in mixed-precision training causes about $\pm$2\%
variance between runs.
Second, the training set has only 124 \textsc{Disputed} examples
(10.1\%), making it hard to learn good decision boundaries for this
class.
Third, our Recall@100 ceiling of 61\% means that for almost 40\% of
claims, the correct evidence never enters the candidate pool no matter
how good the reranker is.
Fourth, the conflict-aware aggregator works with a 31-dimensional
feature space over just 1{,}228 training examples --- a setting where
overfitting is a real risk even with L2 regularisation.
Finally, we can only use the provided dataset and cannot add external
fact-checking data, which limits the variety of conflict patterns the
system can learn from.
